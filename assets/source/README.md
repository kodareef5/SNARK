# Editable art

Store original models, textures, animation sources, audio sources, and other
editable authoring inputs here. Keep source files and exports tied to the same
content/asset identity, with authorship and export instructions.

External authoring tools may be used; they do not become game runtime
dependencies. Do not serve editable source files to the browser. First deliver
one small original model after the
[handoff conventions](../../planning/architecture/contracts.md) are agreed.
No source assets exist yet.
