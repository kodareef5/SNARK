# Thrown case references

- **Smoke grenade.** AceCamp’s waterproof matchbox has a tall, narrow orange body. The game prop keeps that signaling color and adds dark collars and a pale stripe that crosses the middle. [AceCamp, Orange Waterproof Matchbox](https://www.acecamp.com/orange-waterproof-matchbox/)
- **Poison grenade.** The Nalgene wide-mouth lab bottle has curved shoulders and a broad cap. The game prop uses those proportions in a squat green pod with a dark foot and a pale brass crown. [Thermo Fisher Scientific, Nalgene 2105](https://www.thermofisher.com/order/catalog/product/2105-0032)
- **C4.** Klein’s canvas tool pouch has a long rectangle of fabric with softened corners. The game prop takes that outline into a fuller block with two dark wraps and a raised orange patch. [Klein Tools, Canvas Tool Pouch 5139](https://www.kleintools.com/catalog/zipper-tool-bags/zipper-bag-canvas-tool-pouch-125-x-7-x-07-inch)
