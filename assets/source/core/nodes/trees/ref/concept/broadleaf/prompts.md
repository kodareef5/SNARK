# Exact image-generation prompts

Round 2 banyan prompts are recorded at the end of this file. All image inputs are our own paintings in this folder.

Tool: built-in `image_gen.imagegen`. Initial paintings were generated from words alone. Later image inputs are original paintings generated for this task. No photographs or existing game art were used. Native PNGs are retained without resizing or resampling. Requested sizes in prompts are requests; actual output dimensions are listed in `DESIGN.md`.
