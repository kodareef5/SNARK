I inspected the supplied wood layers and report first. I kept its useful requirements—physical scale, aligned layers, independent normal verification and numerical seam checks—and added metallic relighting with the actual roughness and metalness, plus strips at the requested dimensions.

The first rendered version had rust that looked too bright and separate from the metal. I sent it back through the build: darkened the oxide from orange-brown toward umber, softened its spread, reduced the proportion of thick cores and darkened oxide inside pits. I also corrected roughness extrema that initially fell outside the requested bands. The earlier images and metrics remain in `checks/review01/`. The final inspection uses a more moderate softbox intensity; all four final light views share the same exposure. I examined the rebuilt outputs, rather than relying on the numerical pass alone.

To rebuild and check, with Python 3, Pillow, NumPy and SciPy installed:

```sh
python3 build_material.py
python3 check_material.py
```

Both scripts write only beside themselves. `surface_fields.npz` is the retained authoring/check cache, not an engine texture. The final build took **11.6 seconds**; the final check/render pass took approximately **3.2 seconds** on this machine. Generation, scripting, revisions and visual inspection are included in the wall-clock time below.

For engine import, enable sRGB only on `iron_base.png`. Import height, normal and ORM as linear data and use repeat wrapping on u and v. Keep the normal at strength 1.0 and use OpenGL green-channel orientation. Map 0–1 height to 0–3 mm; if displacement needs a centred origin, use 0.5 / 1.5 mm as the midpoint. The four PNGs are the complete runtime layer set.

Limitations: this is an authored material, not a measured iron scan. AO is a shallow cavity estimate; the preview environment is an approximation, not a path-traced scene. I have not tested a particular engine's compression or mip generation. The smallest 5 mm hammer marks occupy only about 3.4 texels, so they will soften at distance. A long enough inspection of repeated tiles can still find repeated rust shapes, but no one feature draws my eye in the 3×3 view or the strap samples. I am satisfied with the surface for the intended door fittings; final engine lighting remains the outstanding context check.
