# Thatch: the wall and roof material of the first building tier

You are making one tiling material for a survival game in which players build bases out of square pieces (foundations, walls, doorways, ceilings) by the thousand. This material is what the cheapest tier is made of: bundled reed thatch lashed to a frame of poles. It is the first shelter a player builds: light, uneven, quick to put up, and it should look it, and still be a pleasure to look at. It covers the faces of every thatch wall, doorway and door, and the top of every thatch ceiling, which is the roof. Thousands of square metres of it will be on screen at once, from arm's length to across a valley.

Work only in the current folder. Take as long as the job needs.

## What it shows

Reed or long-straw thatch hung in horizontal **courses**, like a thatched roof turned upright. Each course is a row of **bundles** standing side by side: a bundle is a sheaf of dry reed stems about 12 cm across, tied near its top with a twisted grass band and hung from a batten, and the stems run downward and end in a ragged fringe of tips. The fringe of each course hangs over the tied top of the course below, so the ties are only half visible in the shadow under it. Bundles in neighbouring courses are staggered by about half a bundle, like brickwork, so the wall reads as bundled, not as one sheet of straw.

- Stems: dry, sun-bleached reed and straw, from pale cream to golden tan, a few darker grey-brown older stems, a little greying toward the exposed tips. No green, nothing orange or saturated. The mean colour of the base colour should be close to sRGB (190, 166, 112).
- Bundles vary: width from about 9 to 15 cm, some fuller, some leaning a few degrees, the odd stray stem crossing its neighbours. The tips at the bottom of each course are ragged and uneven, not a straight cut.
- Handmade and a little rough, not tidy and not dilapidated: no holes, no rot, no moss.

## The layout, which the geometry depends on

- One tile covers **1.5 m by 1.5 m** of wall at **2048 by 2048 pixels** (about 0.73 mm a pixel).
- Columns of the picture run along the wall. Row 0 is the top. Stems run down the picture.
- There are exactly **four courses per tile**, each **512 pixels (37.5 cm) tall**. A course's top edge is at row 0, 512, 1024 and 1536. The game's geometry steps out at exactly those rows: each course is a face sloping outward from its top edge to its bottom edge, and under each course's bottom edge the surface steps back to the next course's top. So the top 10 to 15% of each course is the tied part, set back in shadow, with the previous course's fringe tips painted hanging over it; the body is stems; the lowest part is the start of its own fringe, which continues past the course boundary onto the next course's top.
- Each course must contain a whole number of bundles across the tile, so it tiles left to right; neighbouring courses are staggered.
- Each of the four courses should look different from the others (different bundle widths and leans), while all four belong together.

## What to deliver, all 2048 by 2048 and pixel-aligned (the same stem in the same place in every layer)

1. `thatch_base.png`: base colour, sRGB, 8-bit RGB. Flat and unlit: no baked light, no cast shadow, no highlights, no ambient occlusion darkening beyond the real colour of the stems. The tied part under the overhang is not painted dark here; its darkness belongs in the occlusion channel.
2. `thatch_height.png`: 16-bit greyscale height, white is high. Local relief only: the stems, the rounding of each bundle, the tie bands, the tips standing proud. **Do not** add the slope of each course or the step between courses: the geometry already has them, and a normal map that also had them would double them. Say in your report how many millimetres the full range stands for (about 25 to 40 mm is right).
3. `thatch_normal.png`: tangent-space normal map, **OpenGL convention** (green points to the top of the picture), computed from the delivered height with wrap-around, at the physical scale above, so it agrees with the height.
4. `thatch_orm.png`: one packed picture, linear, 8-bit RGB: **red** ambient occlusion (the shadow under each overhang, between bundles and between stems), **green** roughness (dry straw is rough, about 0.75 to 0.95, the tie bands a little smoother), **blue** metalness (0 everywhere).

Keep the generated source pictures at full size in `source/`, and the scripts that build every layer (`build_material.py`) and check them (`check_material.py`) in this folder, so the whole thing can be rebuilt.

# Image Generation Skill

Generates or edits images for the current project (for example website assets, game assets, UI mockups, product mockups, wireframes, logo design, photorealistic images, or infographics).

## Top-level modes and rules

This skill has exactly two top-level modes:

- **Default built-in tool mode (preferred):** built-in `image_gen` tool for image generation, editing, and transparent-image requests. Does not require `OPENAI_API_KEY`.
- **Fallback CLI mode:** `scripts/image_gen.py` CLI. Use when the user explicitly asks for or confirms the CLI/API/model path. Requires `OPENAI_API_KEY`.

Within CLI fallback, the CLI exposes three subcommands:

- `generate`
- `edit`
- `generate-batch`

Rules:
- Use the built-in `image_gen` tool by default for normal image generation and editing requests.
- Do not switch to CLI fallback for ordinary quality, size, or file-path control.
- For transparent images, ask built-in `image_gen` for a transparent background and preserve the generated alpha.
- Never silently switch from built-in `image_gen` or CLI `gpt-image-2` to CLI `gpt-image-1.5`; ask the user first unless they explicitly requested `gpt-image-1.5`.
- The word `batch` by itself does not mean CLI fallback. If the user asks for many assets or says to batch-generate assets without explicitly asking for CLI/API/model controls, stay on the built-in path and issue one built-in call per requested asset or variant.
- If the built-in tool fails or is unavailable, tell the user the CLI fallback exists and that it requires `OPENAI_API_KEY`. Proceed only if the user explicitly asks for that fallback.
- If the user explicitly asks for CLI mode, use the bundled `scripts/image_gen.py` workflow. Do not create one-off SDK runners.
- Never modify `scripts/image_gen.py`. If something is missing, ask the user before doing anything else.

Built-in save-path policy:
- In built-in tool mode, Codex saves generated images under `$CODEX_HOME/*` by default.
- Do not describe or rely on OS temp as the default built-in destination.
- Do not describe or rely on a destination-path argument (if any) on the built-in `image_gen` tool. If a specific location is needed, generate first and then move or copy the selected output from `$CODEX_HOME/generated_images/...`.
- Save-path precedence in built-in mode:
  1. If the user names a destination, move or copy the selected output there.
  2. If the image is meant for the current project, move or copy the final selected image into the workspace before finishing.
  3. If the image is only for preview or brainstorming, render it inline; the underlying file can remain at the default `$CODEX_HOME/*` path.
- Never leave a project-referenced asset only at the default `$CODEX_HOME/*` path.
- Do not overwrite an existing asset unless the user explicitly asked for replacement; otherwise create a sibling versioned filename such as `hero-v2.png` or `item-icon-edited.png`.

## When to use
- Generate a new image (concept art, product shot, cover, website hero)
- Generate a new image using one or more reference images for style, composition, or mood
- Edit an existing image (inpainting, lighting or weather transformations, background replacement, object removal, compositing, transparent background)
- Produce many assets or variants for one task

## When not to use
- Extending or matching an existing SVG/vector icon set, logo system, or illustration library inside the repo
- Creating simple shapes, diagrams, wireframes, or icons that are better produced directly in SVG, HTML/CSS, or canvas
- Making a small project-local asset edit when the source file already exists in an editable native format
- Any task where the user clearly wants deterministic code-native output instead of a generated bitmap

## Decision tree

Think about two separate questions:

1. **Intent:** is this a new image or an edit of an existing image?
2. **Execution strategy:** is this one asset or many assets/variants?

Intent:
- If the user wants to modify an existing image while preserving parts of it, treat the request as **edit**.
- If the user provides images only as references for style, composition, mood, or subject guidance, treat the request as **generate**.
- If the user provides no images, treat the request as **generate**.

Built-in edit semantics:
- Built-in edit mode is for images already visible in the conversation context, such as attached images or images generated earlier in the thread.
- If the user wants to edit a local image file with the built-in tool, first load it with built-in `view_image` tool so the image is visible in the conversation context, then proceed with the built-in edit flow.
- Do not promise arbitrary filesystem-path editing through the built-in tool.
- If a local file still needs direct file-path control, masks, or other explicit CLI-only parameters, use the explicit CLI fallback only when the user asks for it.
- For edits, preserve invariants aggressively and save non-destructively by default.

Execution strategy:
- In the built-in default path, produce many assets or variants by issuing one `image_gen` call per requested asset or variant.
- In the CLI fallback path, use the CLI `generate-batch` subcommand only when the user explicitly chose CLI mode and needs many prompts/assets.
- For many distinct assets, do not use `n` as a substitute for separate prompts. `n` is for variants of one prompt; distinct assets need distinct built-in calls or distinct CLI `generate-batch` jobs.

Assume the user wants a new image unless they clearly ask to change an existing one.

9. Augment the prompt based on specificity:

17. If the user explicitly chooses or confirms the CLI fallback, then use the fallback-only docs for model, quality, size, `input_fidelity`, masks, output format, output paths, and network setup.

## Prompt augmentation

Reformat user prompts into a structured, production-oriented spec. Make the user's goal clearer and more actionable, but do not blindly add detail.

Treat this as prompt-shaping guidance, not a closed schema. Use only the lines that help, and add a short extra labeled line when it materially improves clarity.

### Specificity policy

Use the user's prompt specificity to decide how much augmentation is appropriate:

- If the prompt is already specific and detailed, preserve that specificity and only normalize/structure it.
- If the prompt is generic, you may add tasteful augmentation when it will materially improve the result.

Allowed augmentations:
- composition or framing hints
- polish level or intended-use hints
- practical layout guidance
- reasonable scene concreteness that supports the stated request

Not allowed augmentations:
- extra characters or objects that are not implied by the request
- brand names, slogans, palettes, or narrative beats that are not implied
- arbitrary side-specific placement unless the surrounding layout supports it

## gpt-image-2 guidance for CLI fallback

The fallback CLI defaults to `gpt-image-2`.

- Use `gpt-image-2` for new CLI/API workflows unless the user confirms a different model.
- CLI `gpt-image-2` does not support `background=transparent`; ask before using `gpt-image-1.5` unless the user explicitly requested that model.
- `gpt-image-2` always uses high fidelity for image inputs; do not set `input_fidelity` with this model.
- `gpt-image-2` supports `quality` values `low`, `medium`, `high`, and `auto`.
- Use `quality low` for fast drafts, thumbnails, and quick iterations. Use `medium`, `high`, or `auto` for final assets, dense text, diagrams, identity-sensitive edits, or high-resolution outputs.
- Square images are typically fastest to generate. Use `1024x1024` for fast square drafts.
- If the user asks for 4K-style output, use `3840x2160` for landscape or `2160x3840` for portrait.
- `gpt-image-2` size may be `auto` or `WIDTHxHEIGHT` if all constraints hold: max edge `<= 3840px`, both edges multiples of `16px`, long-to-short ratio `<= 3:1`, total pixels between `655,360` and `8,294,400`.

Popular `gpt-image-2` sizes:
- `1024x1024` square
- `1536x1024` landscape
- `1024x1536` portrait
- `2048x2048` 2K square
- `2048x1152` 2K landscape
- `3840x2160` 4K landscape
- `2160x3840` 4K portrait
- `auto`

You are making one tiling material for a survival game in which players build bases out of square pieces (foundations, walls, doorways, ceilings) by the thousand. This material is what the cheapest tier is made of: bundled reed thatch lashed to a frame of poles. ## What it shows

Reed or long-straw thatch hung in horizontal **courses**, like a thatched roof turned upright. Each course is a row of **bundles** standing side by side: a bundle is a sheaf of dry reed stems about 12 cm across, tied near its top with a twisted grass band and hung from a batten, and the stems run downward and end in a ragged fringe of tips. The fringe of each course hangs over the tied top of the course below, so the ties are only half visible in the shadow under it. Bundles in neighbouring courses are staggered by about half a bundle, like brickwork, so the wall reads as bundled, not as one sheet of straw.

- Stems: dry, sun-bleached reed and straw, from pale cream to golden tan, a few darker grey-brown older stems, a little greying toward the exposed tips. No green, nothing orange or saturated. The mean colour of the base colour should be close to sRGB (190, 166, 112).
- Bundles vary: width from about 9 to 15 cm, some fuller, some leaning a few degrees, the odd stray stem crossing its neighbours. The tips at the bottom of each course are ragged and uneven, not a straight cut.
- Handmade and a little rough, not tidy and not dilapidated: no holes, no rot, no moss.

## The layout, which the geometry depends on

- One tile covers **1.5 m by 1.5 m** of wall at **2048 by 2048 pixels** (about 0.73 mm a pixel).
- Columns of the picture run along the wall. Row 0 is the top. Stems run down the picture.
- There are exactly **four courses per tile**, each **512 pixels (37.5 cm) tall**. A course's top edge is at row 0, 512, 1024 and 1536. The game's geometry steps out at exactly those rows: each course is a face sloping outward from its top edge to its bottom edge, and under each course's bottom edge the surface steps back to the next course's top. So the top 10 to 15% of each course is the tied part, set back in shadow, with the previous course's fringe tips painted hanging over it; the body is stems; the lowest part is the start of its own fringe, which continues past the course boundary onto the next course's top.

"""Rebuild the 1.5 m periodic thatch material. Requires NumPy, SciPy, Pillow.

The source image contributes high-pass epidermis only, not lighting or layout.
All objects are rasterized once into common colour/height/AO/roughness/ID fields.
No course ramp or course step is present in the height field.
"""
from pathlib import Path
import json, hashlib, time
import numpy as np
from PIL import Image, ImageCms
from scipy.ndimage import gaussian_filter, map_coordinates

ROOT = Path(__file__).resolve().parent
N = 2048
COURSE = 512
LOCAL_H = 640
METRES = 1.5
HEIGHT_MM = 32.0
SEED = 314159
TARGET = np.array([190., 166., 112.], np.float32)
SRGB = ImageCms.ImageCmsProfile(ImageCms.createProfile('"'sRGB')).tobytes()

def smooth(a, b, x):
    t = np.clip((x-a)/(b-a), 0, 1)
    return t*t*(3-2*t)

def save_rgb(name, x, srgb=False):
    im = Image.fromarray(np.uint8(np.clip(np.rint(x),0,255)), 'RGB')
    im.save(ROOT/name, **({'icc_profile':SRGB} if srgb else {}))

def normal_from_height(h):
    spacing = METRES*1000/N
    dx = (np.roll(h,-1,1)-np.roll(h,1,1))*HEIGHT_MM/(2*spacing)
    dy = (np.roll(h,-1,0)-np.roll(h,1,0))*HEIGHT_MM/(2*spacing)
    v = np.stack([-dx,dy,np.ones_like(h)],-1) # tangent +Y is image-up
    return v/np.linalg.norm(v,axis=-1,keepdims=True)

def source_detail():
    src = np.asarray(Image.open(ROOT/'source/generated_reed_stock.png').convert('RGB'),np.float32)
    lum = src@np.array([.2126,.7152,.0722],np.float32)
    # Remove the original image's stalk-scale light/shade. Only weak local
    # epidermal speckle survives; procedural pigment supplies the stem colours.
    detail = lum-gaussian_filter(lum,(3.0,1.7),mode='reflect')
    detail = np.clip(detail,-12,12)/12
    return detail.astype(np.float32)

class Course:
    def __init__(self):
        self.col = np.empty((LOCAL_H,N,3),np.float32); self.col[:]=TARGET
        self.h = np.full((LOCAL_H,N),8.,np.float32)
        self.ao = np.full((LOCAL_H,N),.77,np.float32)
        self.rough = np.full((LOCAL_H,N),.9,np.float32)
        self.alpha = np.zeros((LOCAL_H,N),np.float32)
        self.ids = np.zeros((LOCAL_H,N),np.uint16)
        self.ties = np.zeros((LOCAL_H,N),np.float32)
        self.bundle = np.zeros((LOCAL_H,N),np.uint8)

    def paint(self, xx, yy, a, col, h, ao, rough, ident, tie=0, bundle=0):
        ix = (xx.astype(int)%N)[None,:]
        iy = yy.astype(int)[:,None]
        a = np.clip(a,0,1)
        a3=a[...,None]
        self.col[iy,ix] = self.col[iy,ix]*(1-a3)+col*a3
        for ar,v in [(self.h,h),(self.ao,ao),(self.rough,rough)]:
            ar[iy,ix]=ar[iy,ix]*(1-a)+v*a
        self.alpha[iy,ix] = 1-(1-self.alpha[iy,ix])*(1-a)
        self.ids[iy,ix] = np.where(a>.5,ident,self.ids[iy,ix])
        self.ties[iy,ix] = self.ties[iy,ix]*(1-a)+tie*a
        self.bundle[iy,ix] = np.where(a>.5,bundle,self.bundle[iy,ix])


def build_course(k, detail, metadata):
    rng = np.random.default_rng(SEED+k*8761)
    c = Course()
    n = 12
    nominal = N/n
    offset = [0,nominal*.5,9,nominal*.5+9][k]
    while True:
        jitter = rng.uniform(-21,21,n)
        edges = np.arange(n)*nominal + jitter + offset
        widths = np.diff(np.r_[edges,edges[0]+N])
        if widths.min()>=123 and widths.max()<=205: break
    records=[]
    for b,(left,w) in enumerate(zip(edges,widths)):
        centre = left+w*.5
        lean = rng.uniform(-19,19)
        curve = rng.uniform(-5,5)
        crown = rng.uniform(8.5,12.0)
        tie_y = rng.uniform(42,58)
        tip_bias = rng.uniform(-7,7)
        bundle_tint = rng.normal(0,2.1)
        bid=k*n+b+1
        rec=dict(id=bid,centre_px=float(centre%N),width_px=float(w),width_cm=float(w*150/N),lean_degrees=float(np.degrees(np.arctan(lean/COURSE))),tie_y_px=float(tie_y))
        records.append(rec)

        def frame(y):
            t=y/COURSE
            mid=centre+lean*(t-.14)+curve*np.sin(t*np.pi)
            # Slight pinch where tied, then mostly parallel stems.
            spread=1-.16*np.exp(-((y-tie_y)/62)**2)+.018*np.sin(2.7*t)
            return mid,spread

        # Buried stems followed by the visible layer. Their random positions
        # and different end lengths avoid regular vertical striping.
        for layer in (0,1):
            pos=-w*.52
            j=0
            while pos<w*.54:
                spacing=rng.uniform(2.1,4.0) if layer else rng.uniform(3.5,5.2)
                pos+=spacing
                j+=1
                radius=rng.uniform(1.5,2.65) if layer else rng.uniform(2.4,3.3)
                if rng.random()<.055: radius*=1.35
                u=pos/w
                bend=rng.uniform(-1.5,1.5)
                phase=rng.uniform(0,2*np.pi)
                # Ragged fringe, individual tapering ends. Dense cover extends
                # across the geometry boundary; ties peek through below it.
                end = 512 + tip_bias + rng.normal(40,19) + 10*np.sin(u*7+phase*.13)
                end=np.clip(end,493,599)
                start=0
                yy=np.arange(start,min(LOCAL_H,int(end+3)),dtype=np.float32)
                mid,sp=frame(yy)
                xline=mid+pos*sp+bend*np.sin(yy/160+phase)+.45*np.sin(yy/42+phase)
                rr=radius*(1-.28*smooth(end-22,end,yy))
                rr*=1+.07*np.sin(yy/75+phase)
                xx=np.arange(np.floor(xline.min()-radius-2),np.ceil(xline.max()+radius+3),dtype=np.float32)
                X=xx[None,:]; Y=yy[:,None]
                d=(X-xline[:,None])/rr[:,None]
                edge=np.clip((1-np.abs(d))*rr[:,None]+.45,0,1)
                # Rounded broken tips, 1-3 px bevel, not a clipped flat line.
                endshape=end-.8*d+.6*np.sin(d*3+phase)
                a=edge*(1-smooth(endshape-2.2,endshape+.4,Y))
                transverse=np.sqrt(np.maximum(0,1-d*d))
                q=(X-mid[:,None])/(w*.55*sp[:,None])
                mound=np.maximum(0,1-q*q)**.75
                h=6.7+crown*mound+(1.1 if layer else -.35)
                h=h+transverse*(radius*.73*.7)+.15*np.sin(Y/43+phase)
                h=h+.045*np.sin(d*13+Y/23+phase)*transverse
                h=h-.45*smooth(end-5,end,Y)
                if rng.random()<.37:
                    node=rng.uniform(75,470)
                    ring=np.exp(-((Y-node-.25*d)/1.1)**2)
                    h+=ring*.36
                else: ring=0
                # Intrinsic pigment: no cylinder highlights and no edge AO.
                grey=rng.random()<.105
                tone=np.clip(rng.normal(0,13.2),-31,29)+bundle_tint
                pigment=TARGET+tone*np.array([.86,.91,.97],np.float32)
                if grey: pigment=TARGET+np.array([-13,-8,4])+tone*.6
                weather=smooth(426,end,Y)*rng.uniform(.35,1)
                slow=2.3*np.sin(Y/rng.uniform(80,180)+phase)+1.1*np.sin(Y/22+phase)
                sx=rng.uniform(5,detail.shape[1]-12)
                sy=rng.uniform(8,detail.shape[0]-900)
                uvx=np.broadcast_to(sx+(d+1)*2.3,X.shape if Y.shape[0]==1 else d.shape)
                uvy=np.broadcast_to(sy+Y*1.35,d.shape)
                skin=map_coordinates(detail,[uvy,uvx],order=1,mode='reflect')
                fleck=.9*np.sin(d*10.8+Y*.025+phase)+.45*np.sin(d*23+Y*.16)
                col=np.empty((*d.shape,3),np.float32)
                col[:]=pigment
                col+=slow[...,None]+skin[...,None]*2.8+fleck[...,None]
                col+=weather[...,None]*np.array([-2.,-.5,6.5])
                col-=np.asarray(ring)[...,None]*np.array([3,3,2])
                # Sparse longitudinal fibre pigment fissure, not cast shading.
                if rng.random()<.23:
                    fiss=np.exp(-((d-rng.uniform(-.6,.6))/.11)**2)
                    fiss*=smooth(70,100,Y)*(1-smooth(end-70,end-30,Y))
                    col-=fiss[...,None]*rng.uniform(4,9)
                ao=.91+.065*transverse-.035*(1-mound)
                rough=np.clip(.855+rng.uniform(-.025,.025)+weather*.035-skin*.012,.78,.94)
                ident=1+k*4000+b*250+layer*120+j
                c.paint(xx,yy,a,col,h,ao,rough,ident,bundle=bid)

        # Twisted dried-grass tie, inset beneath previous course fringe.
        # Two intertwining strands, shallow sag and a restrained binding hitch.
        xx=np.arange(np.floor(centre-w*.45-25),np.ceil(centre+w*.45+25),dtype=np.float32)
        yy=np.arange(max(0,int(tie_y-20)),int(tie_y+23),dtype=np.float32)
        X=xx[None,:]; Y=yy[:,None]
        mid,sp=frame(Y)
        q=(X-mid)/(w*.43)
        band_y=tie_y+4.4*(1-q*q)+rng.uniform(-.025,.025)*(X-centre)
        phase=rng.uniform(0,6.28)
        wavelength=rng.uniform(10,15)
        for s in (0,1):
            twist=(X-centre)*2*np.pi/wavelength+phase+s*np.pi
            strand_y=band_y+1.65*np.sin(twist)
            d=(Y-strand_y)/2.35
            a=np.clip((1-np.abs(d))*2.35+.45,0,1)*(1-smooth(.94,1.01,np.abs(q)))
            prof=np.sqrt(np.maximum(0,1-d*d))
            mound=np.maximum(0,1-((X-mid)/(w*.55*sp))**2)**.75
            h=6.7+crown*mound+2.5+prof*.9+.5*np.cos(twist)
            fibers=np.sin((X-centre)*1.7+(Y-band_y)*4.8+phase)
            col=np.empty((*a.shape,3),np.float32)
            col[:]=TARGET+np.array([-5,-4,-2])+rng.normal(0,2)
            col+=fibers[...,None]*2.1+np.sin(twist)[...,None]*1.4
            c.paint(xx,yy,a,col,h,.84+.10*prof,.785+.014*fibers,20000+bid,tie=1,bundle=bid)
        # Small crossing wrap at the off-centre fastening; no repeating bow.
        knotx=centre+rng.uniform(-.22,.22)*w
        xd=(X-knotx)
        yd=Y-(tie_y+4.4)+.65*xd
        ka=np.clip((1-np.abs(yd)/2.4)*2.4+.4,0,1)*(1-smooth(3,6,np.abs(xd)))
        kh=6.7+crown*np.maximum(0,1-q*q)**.75+5.0
        kc=np.empty((*ka.shape,3),np.float32);kc[:]=TARGET+np.array([-4,-3,-1])
        c.paint(xx,yy,ka,kc,kh,.91,.78,21000+bid,tie=1,bundle=bid)

        # A handful of fine stray fibres, embedded in the common fields.
        # They wander a little across the sheaf, without long signature motifs.
        for s in range(rng.integers(2,5)):
            start=rng.uniform(100,290); end=rng.uniform(410,565)
            yy=np.arange(int(start),int(end+2),dtype=np.float32); Y=yy[:,None]
            mid,sp=frame(yy)
            loc=rng.uniform(-.43,.43)*w
            slope=rng.uniform(-.08,.08)
            line=mid+loc*sp+slope*(yy-start)+rng.uniform(-3,3)*np.sin((yy-start)/(end-start)*np.pi)
            radius=rng.uniform(.55,1.05)
            xx=np.arange(np.floor(line.min()-2),np.ceil(line.max()+3),dtype=np.float32);X=xx[None,:]
            d=(X-line[:,None])/radius
            a=np.clip((1-np.abs(d))*radius+.4,0,1)*smooth(start,start+6,Y)*(1-smooth(end-5,end,Y))
            q=(X-mid[:,None])/(w*.55*sp[:,None])
            h=6.7+crown*np.maximum(0,1-q*q)**.75+3.1+np.sqrt(np.maximum(0,1-d*d))*.65
            col=np.empty((*d.shape,3),np.float32);col[:]=TARGET+rng.uniform(-8,16)
            col+=1.5*np.sin(Y/17)[...,None]
            c.paint(xx,yy,a,col,h,.94,.88,23000+bid,bundle=bid)
    metadata.append({'course':k,'top_row':k*512,'bundles':records})
    return c


def build():
    t=time.monotonic()
    (ROOT/'source').mkdir(exist_ok=True)
    detail=source_detail()
    metadata=[]
    courses=[]
    for k in range(4):
        print(f'Rasterizing course {k+1}/4',flush=True)
        courses.append(build_course(k,detail,metadata))
    col=np.empty((N,N,3),np.float32)
    h=np.empty((N,N),np.float32)
    ao=np.empty_like(h); rough=np.empty_like(h)
    ids=np.zeros((N,N),np.uint16); ties=np.zeros_like(h); bundle=np.zeros((N,N),np.uint8)
    overhang=np.zeros_like(h); cover=np.zeros_like(h)
    for k,c in enumerate(courses):
        p=courses[(k-1)%4]
        a=p.alpha[512:640]
        # Soft occlusion on the receiving course; never multiplied into albedo.
        y=np.arange(512,dtype=np.float32)[:,None]
        under=.46+.54*smooth(13,110,y)
        acol=c.col[:512].copy(); ah=c.h[:512].copy()
        aa=c.ao[:512].copy()*under; ar=c.rough[:512].copy()
        ai=c.ids[:512].copy(); at=c.ties[:512].copy(); ab=c.bundle[:512].copy()
        acol[:128]=acol[:128]*(1-a[...,None])+p.col[512:640]*a[...,None]
        # These are individual raised fringe tips, never a whole-course step.
        ph=np.maximum(p.h[512:640],ah[:128]+1.6)
        ah[:128]=ah[:128]*(1-a)+ph*a
        aa[:128]=aa[:128]*(1-a)+p.ao[512:640]*a
        ar[:128]=ar[:128]*(1-a)+p.rough[512:640]*a
        ai[:128]=np.where(a>.5,p.ids[512:640],ai[:128])
        ab[:128]=np.where(a>.5,p.bundle[512:640],ab[:128])
        at[:128]*=(1-a)
        sl=slice(k*512,(k+1)*512)
        col[sl]=acol;h[sl]=ah;ao[sl]=aa;rough[sl]=ar;ids[sl]=ai;ties[sl]=at;bundle[sl]=ab
        overhang[k*512:k*512+128]=a
        cover[sl]=c.alpha[:512]
    # Small cavity AO on each side of every physical strand and bundle.
    cavity=np.maximum(0,gaussian_filter(h,2.4,mode='wrap')-h)
    wide=np.maximum(0,gaussian_filter(h,(3,11),mode='wrap')-h)
    ao*=np.exp(-.095*cavity-.032*wide)
    ao=np.clip(ao,.24,1)
    # One modest smoothing kernel is part of the authored physical height,
    # taking subpixel raster stair-steps off hard ends before differentiation.
    h=gaussian_filter(h,.48,mode='wrap')
    if np.min(h)<0 or np.max(h)>HEIGHT_MM: raise ValueError('Height outside physical range')
    # No albedo AO: force only the global pigment mean, not row brightness.
    col+=TARGET-col.mean(axis=(0,1),dtype=np.float64)
    col=np.clip(col,0,255)
    save_rgb('thatch_base.png',col,True)
    h16=np.uint16(np.rint(h/HEIGHT_MM*65535))
    Image.fromarray(h16).save(ROOT/'thatch_height.png')
    hq=h16.astype(np.float32)/65535
    normal=normal_from_height(hq)
    save_rgb('thatch_normal.png',(normal*.5+.5)*255)
    save_rgb('thatch_orm.png',np.stack([ao,rough,np.zeros_like(ao)],-1)*255)
    Image.fromarray(ids).save(ROOT/'source/stem_ids.png')
    Image.fromarray(bundle).save(ROOT/'source/bundle_ids.png')
    Image.fromarray(np.uint8(np.rint(ties*255))).save(ROOT/'source/tie_mask.png')
    Image.fromarray(np.uint8(np.rint(overhang*255))).save(ROOT/'source/fringe_mask.png')
    save_rgb('source/pigment_master.png',col,True)
    meta={'seed':SEED,'size':[N,N],'metres_per_tile':METRES,'millimetres_per_pixel':METRES*1000/N,'height_full_range_mm':HEIGHT_MM,'height_occupied_mm':[float(hq.min()*HEIGHT_MM),float(hq.max()*HEIGHT_MM)],'geometry_course_top_rows':[0,512,1024,1536],'courses':metadata,'generated_source_dimensions':list(Image.open(ROOT/'source/generated_reed_stock.png').size),'generated_source_sha256':hashlib.sha256((ROOT/'source/generated_reed_stock.png').read_bytes()).hexdigest(),'mean_srgb':np.array(Image.open(ROOT/'thatch_base.png')).mean((0,1)).tolist(),'build_seconds':time.monotonic()-t,'height_note':'Local bundle crowns, reed cylinders, ties and fringe tips only. No course ramp, step, or albedo-derived broad displacement.'}
    (ROOT/'source/build_manifest.json').write_text(json.dumps(meta,indent=2)+'\\n')
    print(json.dumps({k:meta[k] for k in ['mean_srgb','height_occupied_mm','build_seconds']},indent=2))

def render(base,norm,orm,light):
    L=np.array(light,np.float32);L/=np.linalg.norm(L)
    diff=np.maximum(0,norm@L)
    ao=orm[...,0]/255
    rough=orm[...,1]/255
    # Broad dielectric response, intended as a local relief diagnostic.
    V=np.array([0,0,1],np.float32)
    H=L+V;H/=np.linalg.norm(H)
    ndh=np.maximum(norm@H,0)
    spec=.018*ndh**(2/np.maximum(rough,.1)**4)*diff
    rgb=srgb_decode(base/255)*(.33*ao[...,None]+.82*diff[...,None]*(.7+.3*ao[...,None]))+spec[...,None]

def seams(a):
    if a.ndim==2:a=a[...,None]
    a=a.astype(np.float64)
    out={}
    for axis,label in [(1,'"'left_right'),(0,'top_bottom')]:
        delta=np.abs(np.diff(a,axis=axis))
        border=np.abs(np.take(a,0,axis=axis)-np.take(a,-1,axis=axis))
        # Distribution of entire interior line mean differences is a fair
        # comparison with the mean difference along the wrap line.
        reduce=(0,2) if axis==1 else (1,2)
        lines=delta.mean(axis=reduce)
        out[label]={'wrap_mean':float(border.mean()),'interior_mean':float(lines.mean()),'interior_line_p95':float(np.percentile(lines,95)),'interior_line_p99':float(np.percentile(lines,99)),'ratio_to_interior_mean':float(border.mean()/max(lines.mean(),1e-9)),'wrap_pixel_p95':float(np.percentile(border,95))}
    return out

def smooth(a,b,x):
    t=np.clip((x-a)/(b-a),0,1)
    return t*t*(3-2*t)


def save_rgb(path,a,srgb=False):
    Image.fromarray(np.uint8(np.clip(np.rint(a),0,255))).save(ROOT/path,**({'icc_profile':SRGB} if srgb else {}))


def mincut(error):
    \"\"\"Top-to-bottom minimum-error seam, allowing one-pixel lateral steps.\"\"\"
    rows,cols=error.shape
    total=error[0].astype(np.float64).copy()
    back=np.zeros((rows,cols),np.int8)
    for y in range(1,rows):
        prev=np.stack([np.r_[np.inf,total[:-1]],total,np.r_[total[1:],np.inf]])
        choice=np.argmin(prev,axis=0)
        back[y]=choice-1
        total=error[y]+prev[choice,np.arange(cols)]
    path=np.empty(rows,np.int32);path[-1]=np.argmin(total)
    for y in range(rows-1,0,-1):path[y-1]=path[y]+back[y,path[y]]
    return path


def register_source():

    H,W=src.shape[:2]
    overlap=W-PERIOD
    a=src[:,:overlap];b=src[:,PERIOD:]
    err=np.mean((a-b)**2,axis=2)
    # Prefer a central cut, avoiding tiny slivers at the ends of the overlap.
    err+=((np.arange(overlap)-(overlap-1)/2)/(overlap*.45))**8*10000
    cut=mincut(gaussian_filter(err,(1,.6)))
    mask=smooth(-.65,.65,np.arange(overlap)[None,:]-cut[:,None])

def normals(h):
    mm_per_px=METRES*1000/N
    dx=(np.roll(h,-1,1)-np.roll(h,1,1))*HEIGHT_MM/(2*mm_per_px)
    dy=(np.roll(h,-1,0)-np.roll(h,1,0))*HEIGHT_MM/(2*mm_per_px)
    v=np.stack([-dx,dy,np.ones_like(h)],-1)
    return v/np.linalg.norm(v,axis=2,keepdims=True)


def geometry_fields(tex):
    \"\"\"Bundle crowns and local tie masks. No slope or step per course.\"\"\"
    rng=np.random.default_rng(SEED)
    yy,xx=np.mgrid[:N,:N].astype(np.float32)
    crowns=[];groups=[];metadata=[]
    tie=np.zeros((N,N),np.float32)
    for k in range(4):
        cc=np.array(CENTRES[k],np.float32)*N/PERIOD
        widths=(np.roll(cc,-1)-np.roll(cc,1))%N/2
        dist=(xx[0][None,:]-cc[:,None]+N/2)%N-N/2
        nearest=np.argmin(np.abs(dist),axis=0)
        dx=dist[nearest,np.arange(N)]
        cw=widths[nearest]
        variation=rng.uniform(8.4,10.4,len(cc))
        profile=np.maximum(0,1-(dx/(cw*.56))**2)**.75*variation[nearest]
        crowns.append(profile)
        groups.append(nearest)
        records=[]
        for b,(cx,w,ty) in enumerate(zip(cc,widths,TIE_Y[k])):
            Y=np.interp(ty,SOURCE_TOPS,np.arange(5)*512)
            q=((xx-cx+N/2)%N-N/2)/(w*.36)
            # The generated ties sag slightly. A soft feature gate avoids a
            # hard elliptical ridge. Fine rope relief comes from the source.
            line=Y+4*(1-q*q)
            gate=np.exp(-((yy-line)/9.2)**4)*(1-smooth(.82,1.06,np.abs(q)))
            tie=np.maximum(tie,gate)
            records.append({'id':k*11+b+1,'centre_px':float(cx),'width_px':float(w),'width_cm':float(w*150/N),'source_tie_y':ty,'tie_y_px':float(Y-k*512)})

    h=np.empty((N,N),np.float32);bundle=np.zeros((N,N),np.uint8)
    for k in range(4):

        # Smoothly exchange the two local cross sections under the fringe;
        # their means are comparable and there is no geometry-sized step.
        t=smooth(2,112,y)
        profile=crowns[(k-1)%4][None,:]*(1-t)+crowns[k][None,:]*t
        h[k*512:(k+1)*512]=profile
        bundle[k*512:(k+1)*512]=groups[k][None,:]+1+k*11
    return h,tie,bundle,metadata


def intrinsic_colour(tex):
    \"\"\"Lift source crevices; transport crest reflectance over each reed.

    Source ridge lighting is used for relief, not left in the pigment image.
    Broad colour and fine epidermal pigment are preserved at reduced strength.
    \"\"\"
    lum=np.sum(tex*np.array([.2126,.7152,.0722],np.float32),axis=2)
    broad=gaussian_filter(lum,(17,12),mode='wrap')
    crest=maximum_filter1d(gaussian_filter(lum,.42,mode='wrap'),7,axis=1,mode='wrap')
    # Plateau-style shadow lift, rather than a bilateral display sharpen.
    lifted=lum+np.maximum(0,crest-lum-5)*.96
    liftmean=gaussian_filter(lifted,(18,11),mode='wrap')
    pigment=(lifted-liftmean)*.9
    # Natural straw chroma is low-frequency intrinsic colour; normalize the
    # overall palette and suppress dark-gap desaturation changes.
    chroma=tex-lum[...,None]
    chroma-=gaussian_filter(chroma,(20,12,0),mode='wrap')
    chroma=np.clip(chroma,-10,10)*.32
    col=TARGET+pigment[...,None]*np.array([.85,.94,1.03])+chroma
    # Longitudinal source colour lives in real straw, not directional light.
    low=gaussian_filter(lum,(22,1.1),mode='wrap')-broad
    col+=np.clip(low,-16,16)[...,None]*.22
    return col.astype(np.float32),lum


def native_fibres():
    rng=np.random.default_rng(SEED+101)
    # Native 2048-resolution, elongated epidermal fibres. All filtering wraps.
    noise=rng.normal(0,1,(N,N)).astype(np.float32)
    f=gaussian_filter(noise,(8.2,.42),mode='wrap')
    f-=gaussian_filter(f,(.4,1.7),mode='wrap')
    f/=f.std()
    f=np.clip(f,-2.6,2.6)
    # Coordinate warp follows the slight naturally varying bundle flow.
    yy,xx=np.mgrid[:N,:N].astype(np.float32)
    warp=1.2*np.sin(yy*2*np.pi/N*9+.35*np.sin(xx*2*np.pi/N*13))
    f=map_coordinates(f,[yy,(xx+warp)%N],order=1,mode='grid-wrap')
    return f
