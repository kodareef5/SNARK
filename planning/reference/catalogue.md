# Content catalogue

Generated by `bun run catalogue` from the class table in
`shared/content/classes.ts`. Do not edit it by hand: change the table and run
the tool.

Every kind of content has a class, as ARK's has. A definition's `type` is its
family and its class is a leaf of this table. The table says what a class must
declare, what it may, and which assets it expects. A field that is in neither
list is refused. Names and ids are this engine's own. The ARK column says what
the class corresponds to, so that what is known of ARK carries over.

There are 41 classes: 27 built, 5 partly built, and 9 stubs that
wait for a feature. The core pack holds 397 definitions, and 80 renames of ids
that are no longer defined.

An asset slot is addressed `owner#slot`, or `owner#slot/key` for a slot with
several values: `core:raptor#clip/walk`. Levels of detail are inside the asset
and are never named by content.

A definition is named by its id. At the console and in a settings file it also
answers to an id it once had, to an alias (`aliases`, which any definition may
declare and no two may share), and to its id's own name where it alone answers
to that: `spear` for `core:spear`. Case is ignored. A creature and its variants
share a `tag`.

## What waits for a feature

Each class below has a row and no content, and each field is declared and
checked and read by nothing. They are filled in when the feature under them is
built.

- **Defences: turrets, spikes, and explosives that are set.** `structure/defence`.
- **Loot: supply crates, fishing, quality, item stat clamps, custom recipes.** `prop/crate`, `loot` (partly built), `species.loot`.
- **Small behaviours of things already built.** `prop/cloud`, `damage` (partly built), `game`, `item.weapon.spread`, `item.weapon.recoil`, `item.weapon.structures`, `item.weapon.cloud`, `item.ammo.pellets`, `item.ammo.falloff`, `item.ammo.blast`, `item.ammo.pierce`, `item.ammo.light`, `item.description`, `item.folder`, `species.attacks`, `species.saddle`, `species.buffs`, `engram.requires`, `buff.good`, `damage.label`, `damage.torpor`, `damage.trueShare`, `damage.melee`.
- **Maps as content: a map, its zones and what lives in them.** `map` (partly built), `engram.group`, `map.label`, `map.game`.
- **Crafting stations: what is made where, and how fast.** `structure/station` (partly built).
- **Skins, dyes, costumes and shields.** `item/shield`, `item/costume`, `item/skin`, `item/dye`.
- **Bosses, artifacts and what a boss unlocks.** `item/artifact`, `species.variant`, `species.boss`, `engram.from`.
