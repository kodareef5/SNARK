# Events

Generated by `bun run events` from the event table in
`server/events/catalog.ts`. Do not edit it by hand: change the table and run the
tool.

An event is what the server tells a module. A **before** event is raised before
the thing happens: a handler may refuse it with a reason, or change the fields
marked "may change". An **after** event says what has happened, in values, and
is delivered once a tick, before the commit. The module contract is in
`server/api/module.ts`.

There are 96 events: 81 raised today, 0 with a place in the code and not
raised yet, and 15 that wait for a feature.

The ARK column says what a plugin for ARK's unofficial server API hooks for the
same purpose. ARK has no event API, so plugins hook the game's own functions.

- **Imprinting and baby care.** `imprint`.

- **A points ledger: a shop, kits and rewards.** `points.changed`.
